=== 6. Why the walk faults at level 2 with the old tables ===

With T0SZ=12 + DS=1, the walk starts at level -1 (QEMU ptw.c computes
level = 4 - (inputsize - 4)/stride = -1 for inputsize=52). The old root table
('idmap', built for T0SZ=16/level-0 root) is then interpreted one level deeper:

  L-1 idx = VA[51:48] = 0 -> idmap[0] = TABLE -> level-1 table '1:'
  L0  idx = VA[47:39] = 0 -> '1:'[0]   = TABLE -> L2 table '20:'   (flash+dev)
  L1  idx = VA[38:30] = 0 -> '20:'[0]  = TABLE -> L3 table '3:'    (first 2 MB)
  L2  idx = VA[29:21] = 0 -> '3:'[0]   = 0x0  ("omit first 4k page", IdMap.S)

  -> invalid descriptor -> Translation fault, level 2 (IFSC 0b00110) — exactly
  the observed ESR. Same for the vector fetch at 0x5200 => infinite storm.
